# Contributing
> [!WARNING]
> This guide assumes that you already have a functional Postgres Server set up.

1. `git clone`
2. Create an EntityFramework migration and update the database to it
3. Rename `appsettings.example.json` to `appsettings.json` and fill in any missing values
4. `docker compose up --build`

# Setup
> [!WARNING]
> In order to start a match properly, at least 7 beatmaps must be present in the database.
